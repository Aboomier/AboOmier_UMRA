# برامج العمرة والحج — هيكل المشروع

مشروع ويب حقيقي (React + Firebase + Cloudinary) مكوّن من:

- **شاشة العميل** (`/`): يستعرض البرامج مجمّعة حسب النوع والشهر
  ("برامج العمرة — أكتوبر 2026"، "برامج العمرة — نوفمبر 2026"...)،
  مع شريط "عروض مميزة"، وشارة "متبقي X يوم" للبرامج القريب موعدها،
  وغلاف علوي وبانر جانبي قابلين للتغيير، ولا يظهر فيها اسم أي شركة إطلاقاً.
- **لوحة التحكم** (`/admin`): محمية بتسجيل دخول، لإضافة/تعديل/حذف
  البرامج والشركات، ورفع الصور، وتفعيل "عرض مميز"، وتغيير غلاف
  وبانر صفحة العميل.
- **قاعدة بيانات Firestore**: أي تعديل تحفظه في لوحة التحكم يظهر
  للعميل فوراً (بدون إعادة نشر).
- **Cloudinary**: تخزين الصور (بوسترات البرامج، الغلاف، البانر)
  — بديل مجاني تماماً عن Firebase Storage، بدون الحاجة لربط بطاقة
  بنكية أو خطة Firebase المدفوعة (Blaze).

## لماذا لم يتم تشغيله هنا مباشرة؟

بيئة المحادثة هذه ليس لديها اتصال إنترنت لتشغيل أوامر مثل
`npm install` أو الاتصال بمشروع Firebase حقيقي. الكود جاهز
وكامل، لكن تشغيله الفعلي يحتاج بيئة متصلة بالإنترنت — إما
جهازك، أو تطبيق **Claude Code** (يمكنه تشغيل الأوامر فعلياً
ومتابعة الأخطاء خطوة بخطوة).

## خطوات التشغيل

### 1) Firebase (Firestore + Authentication فقط — بدون Storage)

1. أنشئ مشروعاً في console.firebase.google.com
2. فعّل **Firestore Database** (Production mode)
3. فعّل **Authentication** → Email/Password → أنشئ مستخدماً واحداً
   (هذا حساب دخولك للوحة التحكم)
4. من إعدادات المشروع → أضف تطبيق ويب، وانسخ القيم إلى ملف `.env`
   (انسخ `.env.example` وأعد تسميته إلى `.env`)
5. من تبويب Rules في Firestore، الصق محتوى `firestore.rules`
   واضغط Publish

### 2) Cloudinary (تخزين الصور مجاناً)

1. أنشئ حساباً مجانياً على cloudinary.com (بدون بطاقة بنكية)
2. من الصفحة الرئيسية للوحة تحكم Cloudinary، انسخ **Cloud name**
   وضعه في `.env` باسم `VITE_CLOUDINARY_CLOUD_NAME`
3. من: Settings → Upload → Upload presets → **Add upload preset**
   - غيّر **Signing Mode** من `Signed` إلى **`Unsigned`**
     (ضروري، لأن الرفع سيتم مباشرة من المتصفح بدون خادم خاص بنا)
   - احفظ، وانسخ اسم الـ preset إلى `.env` باسم
     `VITE_CLOUDINARY_UPLOAD_PRESET`

### 3) التثبيت والتشغيل محلياً

```
npm install
npm run dev
```
افتح `/admin` وسجّل الدخول بالحساب الذي أنشأته، وابدأ بإضافة
شركة ثم برنامج. افتح `/` لترى شاشة العميل.

### 4) النشر

أسهل خيار هو `firebase deploy` (بعد `firebase init hosting`) أو
رفع مجلد `dist` (الناتج من `npm run build`) على Vercel/Netlify
مجاناً.

## لاحقاً: تحويلها لتطبيق على Google Play

بعد نشر الموقع كرابط حقيقي، يمكن تغليفه كتطبيق Android حقيقي
بدون إعادة كتابة الكود، باستخدام تقنية **TWA (Trusted Web
Activity)** عبر أداة Google الرسمية "Bubblewrap" — تنتج ملف
تثبيت (AAB) جاهزاً لرفعه على Google Play، ويعمل كأنه تطبيق أصلي
بأيقونة خاصة به، لكنه في الخلفية نفس موقعك بنفس قاعدة البيانات.

## هيكل الملفات

```
src/
  firebase.js          إعداد الاتصال بـ Firestore + Authentication
  lib/
    firestore.js         كل عمليات القراءة/الكتابة على قاعدة البيانات
    cloudinary.js         رفع الصور (بديل مجاني عن Firebase Storage)
    dateUtils.js           تجميع البرامج حسب الشهر + حساب الأيام المتبقية
  client/                 شاشة العميل (بدون أي ذكر لاسم الشركة)
  admin/                  لوحة التحكم (محمية بتسجيل الدخول)
firestore.rules           قواعد حماية قاعدة البيانات
```
